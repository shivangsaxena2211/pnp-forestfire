THE ORDER OF FOREST GUARDIANS

Smart EcoGuard — an AI-IoT system that watches the forest, estimates the risk of fire, and lets a human deploy suppression.

Our Objective

The Order exists to detect the conditions that precede a forest fire as early as possible, show them clearly to a human operator, and give that operator a single deliberate control to deploy fire suppression. Telemetry is gathered by a remote sensor node, relayed over long-range LoRa radio to an ESP8266 gateway, and read by a Flask backend that scores the risk and serves this dashboard.

The Chain of Enchantment

How a reading travels

Sensor Node

Reads temperature, humidity, pressure and MQ-4 gas, then transmits the reading.

LoRa Radio

SX1278 module at 433 MHz carries the message across the forest.

ESP8266 Gateway

Receives LoRa packets and serves /api/data; sends a LoRa DEPLOY command when asked.

Flask Backend

Polls the gateway, computes the risk score, runs the Random Forest, serves the API.

This Dashboard

Plain HTML, CSS and JavaScript polling the backend every two seconds.

The Ancient Knowledge

Technical details

Fire-Risk Calculation

The backend computes a single weighted environmental index (0–100) from the readings it actually receives: temperature, humidity, MQ-4 gas and, when available, pressure. Missing sensors are left out and the remaining weights are renormalised. The score maps to five levels — minimal, low, moderate, high and critical. The dashboard only displays this value; it never computes its own.

Random Forest Classification

A scikit-learn Random Forest classifies each reading as None, Potential Fire or Confirmed Fire and reports class probabilities. Unless a labelled dataset is supplied, the model is an experimental baseline and is marked so. It is a prediction, not a guarantee.

Fire Suppression Mechanism

Suppression is manual only. After you confirm, the dashboard sends POST /api/deploy; the backend asks the gateway to deploy, and the gateway transmits a LoRa DEPLOY command. Neither the risk score nor the Oracle ever triggers it automatically.

Staleness & Honesty

If the gateway is unreachable or its data is old, the interface says so (ESP OFFLINE / STALE DATA) and shows N/A instead of inventing numbers.
